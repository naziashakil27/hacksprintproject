# Digital Afterimage — 30-Second Hackathon Demo Guide

## Core Story
1. **Origin**: `Employee_Salary_2026.xlsx` created in secure HR Drive.
2. **Propagation**: Shared with Alice (HR) -> Downloaded -> Uploaded to AnalyticsTool -> Transformed into CSV summary -> Shared via external link -> Public Access enabled.
3. **Detection & Reconstruction**: Digital Afterimage connects isolated telemetry events into a unified propagation story.
4. **Explainable Risk**: Deterministic score 95/100 (CRITICAL) with clear factor breakdown (+40 Sensitivity, +25 External, +30 Public Access).
5. **Afterimage Feature**: Scrubbing the time-slider reveals data propagation step-by-step from T0 to T5.
6. **Automated Remediation**: Click "REMEDIATE EXPOSURE" -> n8n workflow triggers containment -> Risk drops to 40 (MEDIUM) -> Verification confirmed.

## Quick Demo Checklist
1. Click **RUN SCENARIO** to watch event sequence build step-by-step.
2. Observe visual evidence badges (**OBSERVED**, **INFERRED**, **UNKNOWN**).
3. Use the **AFTERIMAGE** slider to scrub through time.
4. Review the **AI INVESTIGATION** panel for structured evidence & uncertainties.
5. Expand the **RISK BREAKDOWN** accordion to show judges the transparent risk rules.
6. Click **REMEDIATE EXPOSURE** to execute containment and verify risk reduction.
7. Click **LOAD CLEAN SCENARIO** to show how low-risk internal data movement looks (Score: 25 / LOW).
8. Click **RESET SCENARIO** to restore initial state.
